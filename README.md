# ShopSphere - E-commerce Sales Analysis Dashboard

## Project Overview
ShopSphere is an interactive Power BI dashboard project that analyzes e-commerce sales performance, product revenue, regional sales, and customer demographics using a synthetic sample dataset.

## Project Objectives
- Analyze monthly sales revenue and overall sales performance.
- Identify top-performing products and product categories.
- Compare revenue across regions and customer segments.
- Analyze payment methods and average delivery time.
- Explore customer demographics by region, age group, and gender.

## Tools and Technologies
- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Excel

## Dashboard Pages

### 1. Executive Overview
- Sales Revenue
- Total Orders
- Total Units Sold
- Completed Orders
- Monthly Sales Revenue Trend
- Sales Revenue by Product Category

### 2. Product and Sales Analysis
- Top 10 Products by Revenue
- Revenue by Region
- Sales Revenue by Customer Segment
- Orders by Payment Method
- Average Delivery Days by Region

### 3. Customer Insights
- Unique Customers
- Customers by Region
- Customers by Segment
- Customers by Age Group
- Gender Distribution

## Key Findings
- The West region has the highest revenue in the sample dataset.
- Books & Stationery is the leading product category by revenue.
- Headphones is the highest-revenue product shown in the Top 10 chart.
- The dataset contains 200 unique customers.
- November has the highest monthly revenue in the dashboard.

## Data Model
The project includes five tables:
- Customers
- Orders
- OrderItems
- Products
- Returns

Data was cleaned and transformed using Power Query, and relationships were established between the tables.

## Skills Demonstrated
Data cleaning, data modeling, DAX measures, calculated columns, KPI development, interactive filtering, data visualization, and business analysis.

## Dataset Disclaimer
This project uses a synthetic e-commerce dataset for educational and portfolio purposes. It does not represent actual company transactions or real customer information.

## How to Use
1. Download the Power BI report file from this repository when available.
2. Open the `.pbix` file using Power BI Desktop.
3. Explore the three report pages.
